# 우리집 가계부

PC와 모바일에서 모두 사용 가능한 개인 가계부 앱입니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소(repository) 생성
2. 이 폴더의 파일들을 전부 업로드 (또는 git push)
3. 저장소 → **Settings** → **Pages** → Source를 `main` 브랜치 / `/ (root)` 로 설정 → **Save**
4. 잠시 후 `https://[사용자명].github.io/[저장소명]/` 으로 접속

## 기능

| 화면 | 기능 |
|------|------|
| 홈 | 월별 잔액·수입·지출 요약, 주체별 현황, 최근 내역 |
| 내역 | 월별 전체 거래 목록, 입금/출금/주체 필터 |
| 추가 | 거래 입력 (구분·날짜·계정·주체·내용·금액), 항목 탭 수정 |
| 통계 | 월별 막대 차트, 지출/수입 도넛 차트, 주체별 상세 |

## 계정 분류

- **입금**: 개인연금, 보너스, 월급 + 직접 추가 가능
- **출금**: 주식, 금, 개인연금, 대출금상환, 비과세연금, 생활비 + 직접 추가 가능

## 로그인

**구글 로그인**(Firebase Auth)을 쓴다. 2026-08-20 이전에는 4자리 PIN이 `js/app.js`에
하드코딩돼 있었는데, 이 저장소가 공개라 비밀번호가 그대로 보였다. 되돌리지 말 것.

접근 권한은 RTDB 보안 규칙이 판단한다 — 부부가계부의 **가구 멤버십을 그대로** 쓴다:
`households/{hid}/members/{auth.uid} == true` 인 사람만 읽고 쓴다.
새 사람을 넣으려면 부부가계부 앱에서 초대코드로 가구에 합류시키면 된다.

## 데이터 저장

**Firebase Realtime Database** (`minsung-buboo2` 프로젝트, 경로 `/home-ledger/{hid}`).
부부가계부·민성스케줄·Book Tracker와 같은 프로젝트이고 경로만 다르다.

- localStorage는 이제 **오프라인 캐시**다. 로그인하면 클라우드 값으로 덮어쓴다
- 저장은 1.5초 디바운스 후 문서 전체를 올린다(last-write-wins).
  ⚠ 두 사람이 동시에 고치면 나중 저장이 이긴다. 다른 기기가 먼저 저장했으면
  덮지 않고 토스트로 알린다
- 앱을 다시 열거나 탭으로 돌아오면 서버 `updatedAt`을 확인해 바뀐 경우에만 다시 받는다
- 백업/불러오기 버튼은 그대로 둔다 — 클라우드가 있어도 내보내기는 쓸모가 있다

동기화 코드는 `js/cloud.js` 한 곳에 모여 있다. `js/app.js`는 저장 구조를 모른 채로 두고,
`localStorage.setItem`을 가로채는 방식으로 감쌌다 (71KB를 async로 다시 쓰지 않으려고).

## 배포

⚠ **`git push`로 배포한다.** GitHub 웹 UI 업로드는 쓰지 말 것 —
투자 트래커에서 그 방식 때문에 옛 파일로 되돌아간 적이 있다.
`index.html`·`js/*`를 고치면 **`sw.js`의 캐시 버전도 같이 올린다.** 안 올리면 폰이 옛 파일을 계속 쓴다.
